# Tend button and badge guide

Use this guide for future Tend screens, mockups, and UI changes.

- Use a solid green rounded rectangle for the main action in each group. Use a matching green-outlined rounded rectangle for companion actions. Match height, corner radius, padding, and label weight.
- Use plain green text buttons for low-priority actions that change the current view. Use text links for quiet navigation, a leading chevron for back navigation, and underlines for links in prose.
- Use pills for read-only status, counts, and scores, or for compact selectors with a clear selected state. Give a navigable card one tap target and a trailing chevron.
- Place section actions below the heading and above the affected content. Place the primary action on the left and its companion to the right. Preserve that order when the row wraps.
- Keep Show tended near the completion count above its list. Put Archived Rhythms below the active list as a quiet trailing link. When there are zero items, retain useful count text and omit the inactive control.
- Place Add Season and Log a moment above their lists. Use matching compact outlined buttons and align them left below the heading when space is tight.
- Put one circular gear at the top right of the section it configures. A labeled setup action can appear in an empty state where useful.
- Preserve the existing circled info icon button exactly as designed. Keep it beside the score or heading it explains. Preserve the existing Search and font-size buttons.
- Place Back at top left and Close at top right. Group dialog actions in the footer in Save then Cancel order.
- Keep touch targets at least 44 by 44 CSS pixels on mobile. Preserve visible keyboard focus and allow actions to wrap with enlarged text.
- Preserve well-styled controls. Move them when placement is the only inconsistency. Keep existing behavior and use shared styles and components.
