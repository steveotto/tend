# Tend brand rules (pointer doc)

Source of truth for all Tend work lives in this folder:
- tend-brand.md - exact brand and interface rules (copy, palette, type, voice) - distributed via chat/project attachments
- tend-tokens.css - exact color/style tokens (committed here)
- tend-logo.png - the ONLY approved logo (distributed via chat/project attachments; binary could not be committed through the available push path, but it IS inlined in logo-data.js)
- tend-brand-board.png - visual direction reference only (predates primary statement; also distributed separately)
- BRAND-CHECKLIST.md - run before finishing any revision (distributed separately)

Standing rules:
1. Written guide > board approximations. Never sample colors or fonts from the board image.
2. "Structure beats good intention." = primary statement (onboarding/intro only).
   "Care for what matters." = supporting tagline.
3. Inter 400/500/600 for UI; Newsreader 400 (italic occasional) for editorial prompts only.
4. Forest for primary actions (white text); Mint accents with Ink text; status = color + label/icon.
5. 8px spacing rhythm; cards 20px radius / 24px padding; controls 12px radius, 44px min height.
6. No purple/blue gradients, glass, ornamental illustration, or new accent palettes.
7. No scores for the quality of marriage or faith; no punitive streaks; no hustle language.
8. Generic later requests ("polish it", "make it modern") are NOT rebrand authorization.
9. App icon: no approved export supplied yet - iOS home-screen icon pending matching export from the user.
